## 选择测试

先执行纯 JVM 的解析、选择开关和数量关系测试。应用构建后，在专用 emulator-5584 上执行一次相关启动/启用/同 PID 更新/关闭检查，补充上报身份的正反例。真实 UI 验证只覆盖增加的提示、保存及取消，不重复无关地区选择和全部字段编辑。

0.4.4 的完整六项屏蔽 64 组合保留原 APK、原源码和原始结果。本轮不修改 Methods、策略、共享 native Hook 或六项方法的实现。若实际修改或诊断发现影响这些交互，再执行所影响的步骤；禁止仅因新 APK 哈希而自动从头重跑。旧 64 组合不写成 0.4.5 实测结果，也不在缺少源码绑定时升级为程序化复用证明。

定向模拟器检查超过五分钟时检查耗时，不追加无关用例；保留已通过条目。同一失败没有新证据或修改时不连续重试。测试结束统一恢复原 APK、数据、权限、作用域、系统状态及临时夹具。仅 emulator-5584 可用于测试；本次连接检查 vivo 不在线，无关 emulator-5594 保持原样。
