# 主应用与验证器：原需求复盘

这次复盘由“验证器没有显示 IMEI 等特征码”的实际反馈触发。原来的 0.4.0 有 46 项读取页面，但首页没有任何标识读数，入口名称笼统，进入后先看到机型字段；旧设备状态检查页没有设备标识入口。按用户最初希望方便观察设备特征的要求，这几处展示确实漏了。

|---|---|---|
| 单个应用开启机器伪装，默认关闭，开启后才能配置 | DeviceStore 独立白名单；六项旧屏蔽保留默认开启 | 保留原规则 |

## 需要明确的实际限制

“列出字段”与“系统允许读到真实值”是两件具体的事。Android 10 及以后的真实 IMEI、IMSI、ICCID、序列号通常需要特权或运营商权限。普通电话权限不足时显示系统拒绝读取。模块启用且对应入口被成功注入时，应从实际接口读到合成值，不能让检测页直接照抄档案。

OAID 等依赖厂商服务或 SDK。AOSP 模拟器没有 vivo 真服务，debug 夹具也不能证明真机接口成功。Wi-Fi/蓝牙的 02:00:00:00:00:00 是系统隐私占位地址，显示时标明。空值、超时、服务不存在和权限拒绝分别呈现。

46 项为当前明确实现的目录。内核直读、任意 Binder、硬件认证、其他 SDK、服务端账号关联、公网 IP 和应用私有缓存仍可能暴露信息。“尽量全面”还有这些尚未覆盖的部分，不能把当前实现描述为全部隐藏。静态字段内联或缓存仍可能需要目标应用冷启动。

## 本次测试选择

本次修改设置交互与检测展示/采样，没有改 DeviceField、DeviceProfile、DeviceRead 的各字段适配器、模块 Hook、策略或 native 库。执行首页可见标识、详情 46 项目录/搜索、权限失败文案、预设/随机/手工/取消、前台定时/后台停止/页面切换，以及同进程单标识开启/更新/关闭。安装、版本、签名、四 ABI、正式包排除夹具和恢复记录均核对本次产物。

0.4.0 的 64 组合和全字段还原保持原 APK 哈希和原报告。缺少历史构建输入绑定的记录只作为历史验证背景，不能改写为 0.4.1 的运行结果。本次不重跑未受影响的 64 组合。
